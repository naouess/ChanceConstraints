Simple example

A joint chance constraint requires that all components of a random vector are satisfied simultaneously with probability at least p. This example illustrates the minimal workflow for that case.

Problem. Find the cheapest x with unit costs c such that

\[\mathbb{P}(\xi \le x) \ge p, \qquad \xi \sim \mathcal{N}(\mu, \Sigma), \quad p = 0.9,\]

The covariance Σ has non-zero off-diagonal entries, so the components are correlated and the joint probability cannot be split into independent per-component constraints.

What the example shows.

  1. Building a JuMP model and adding the joint chance constraint with add_JCC_QMC, which uses quasi-Monte Carlo to approximate the probability.
  2. Solving the same problem with add_JCC_SRD, which uses spherical-radial decomposition.
  3. Verifying the optimal solution with an independent estimate of P(ξ ≤ x*), which should be close to p.

Both formulations should give the same optimal cost.

using Main.ChanceConstraints, Ipopt

# Find the cheapest x such that P(ξ ≤ x) ≥ p, where ξ ~ N(μ, Σ)
μ = [5.0, 2.0, 4.0, 3.0]
Σ = [ 2.0  0.5  0.3 -0.1;
      0.5  2.2  0.7  0.4;
      0.3  0.7  1.6 -0.2;
     -0.1  0.4 -0.2  1.8]
p = 0.9
c = [1.0, 1.0, 1.0, 1.0]


model = Model(Ipopt.Optimizer)
set_silent(model)

@variable(model, x[1:4] >= 0.0)
set_start_value.(x, [9.0, 11.45, 9.0, 9.0])

@objective(model, Min, c'x)

# One reliability window starting at index 1 and spanning all 4 time steps (κ = 3)
add_JCC_QMC(model, x, [1], 3, Σ, μ, p)

optimize!(model)

objective_value(model) # ≈ 24.56
value.(x)              # ≈ [7.71, 4.74, 6.47, 5.63]

# ---------------------------------------------------------------
# The same problem with spherical-radial decomposition (SRD).
# SRD needs the mean to be strictly feasible: x ≥ μ + δ
# ---------------------------------------------------------------

model = Model(Ipopt.Optimizer)
set_silent(model)

@variable(model, x[i = 1:4] >= 0.0)
set_start_value.(x, [9.0, 11.45, 9.0, 9.0])

@objective(model, Min, c'x)

add_JCC_SRD(model, x, [1], 3, Σ, μ, p)

optimize!(model)

objective_value(model) # ≈ 24.56
value.(x)              # ≈ [7.71, 4.74, 6.47, 5.63]


# ---------------------------------------------------------------
# Independent check of the joint probability P(ξ ≤ x*)
# ---------------------------------------------------------------

using MvNormalCDF, Random

prob, err = mvnormcdf(Σ, fill(-Inf, 4), value.(x) .- μ;
                      m = 1_000_000, rng = MersenneTwister(1234))
prob # ≈ 0.9

Reservoir problem example

Joint-chance-constrained formulation

A hydropower operator chooses how much water to release from a reservoir in each of T periods. Releases generate revenue, but the water level must stay within safe limits in every period. Because inflows are uncertain, the requirement is stated as a joint chance constraint: the level must stay within its bounds in all periods simultaneously with probability at least p.

Model

Let x[t] be the release in period t and ξ[t] the cumulative inflow up to period t. The water level is

\[\ell_t = \ell_0 + \xi_t - \sum_{s=1}^{t} x_s .\]

The cumulative inflow is ξ ~ N(μ, Σ). It is built from independent yearly inflows with means β_t and variances σ²_t, so

\[\mu_t = \sum_{s=1}^{t} \beta_s, \qquad \Sigma_{ij} = \sum_{s=1}^{\min(i,j)} \sigma^2_s .\]

The cumulative sums make the levels strongly correlated across periods, which is why the constraints must be treated jointly.

The optimization problem is

\[\max_{x} \; \sum_{t=1}^{T} x_t \quad \text{s.t.} \quad \mathbb{P}\big(\ell_{\min} \le \ell_t \le \ell_{\max},\; t = 1,\dots,T\big) \ge p, \qquad x_{min} \le x_t \le x_{max} .\]

Writing it as a joint chance constraint

add_JCC_QMC and add_JCC_SRD handle constraints of the form P(ζ ≤ x) ≥ p with ζ ~ N(μ, Σ), so the level constraints are rewritten in that form.

Single-sided (lower bound only). The constraint ℓ_t ≥ ℓ_min is equivalent to

\[-\xi_t \le \ell_0 - \ell_{\min} - \sum_{s \le t} x_s ,\]

and -ξ ~ N(-μ, Σ). Pass the right-hand side (the slack) as the bound and -μ as the mean:

cumx  = [sum(x[1:t]) for t in 1:T]
slack = [l_0 - l_min - cumx[t] for t in 1:T]
add_JCC_QMC(model, slack, [1], T - 1, Σ, -μ, p)

The window starting at time step [1] with κ = T - 1 covers all T periods in a single joint constraint.

Two-sided (lower and upper bound). The constraint ℓ_min ≤ ℓ_t ≤ ℓ_max is equivalent to lower_t ≤ ξ_t ≤ upper_t with

\[\text{lower}_t = \ell_{\min} - \ell_0 + \sum_{s \le t} x_s, \qquad \text{upper}_t = \ell_{\max} - \ell_0 + \sum_{s \le t} x_s .\]

Stack the bounds as [lower; upper] (length 2T) and set two_sided = true. The random vector still has T components, so κ stays T - 1:

add_JCC_QMC(model, vcat(lower, upper), [1], T - 1, Σ, μ, p; two_sided = true)

What the example shows

  1. Single-sided, QMC and SRD. Both approximations give the same optimal total release.
  2. Two-sided, QMC. Adding the upper bound makes the problem slightly more restrictive. Two-sided implementation is currently not possible using SRD.
  3. Monte Carlo check. The probability that the level stays within bounds is estimated by simulating 200,000 inflow scenarios. It should be close to p = 0.9 for both solutions.
using Main.ChanceConstraints, Ipopt

# Hydropower reservoir over T periods. With cumulative inflow ξ ~ N(μ, Σ) and
# release x_t, the water level is   level_t = l_0 + ξ_t - (x_1 + … + x_t).

# Maximise the total release while keeping the level inside the allowed range
# in all periods jointly with probability p.

T = 3
l_0, l_min, l_max = 5.0, 5.0, 10.0
p = 0.9

β_mean = fill(10.0, T)   # independent yearly inflows with these means …
β_var  = fill(0.5, T)    # … and variances
μ = cumsum(β_mean)
Σ = [sum(β_var[1:min(i, j)]) for i in 1:T, j in 1:T]


# ---------------------------------------------------------------
# Single-sided QMC: only the lower bound  level_t ≥ l_min  matters
# ---------------------------------------------------------------

model = Model(Ipopt.Optimizer)
set_silent(model)

@variable(model, 0 <= x[1:T] <= 30)
set_start_value.(x, 9.0)

@objective(model, Max, sum(x))

cumx = [sum(x[1:t]) for t in 1:T]

# level_t ≥ l_min  ⇔  -ξ_t ≤ l_0 - l_min - cumx_t,  and  -ξ ~ N(-μ, Σ)
slack = [l_0 - l_min - cumx[t] for t in 1:T]
μ_negative = -μ

# One reliability window starting at period 1 and spanning all T periods (κ = T - 1)
add_JCC_QMC(model, slack, [1], T - 1, Σ, μ_negative, p)

optimize!(model)

x_one = value.(x)
objective_value(model) # ≈ 28.43  (only the total is pinned down; the split over periods is not)

# ---------------------------------------------------------------
# Single-sided SRD: only the lower bound  level_t ≥ l_min  matters
# ---------------------------------------------------------------

model = Model(Ipopt.Optimizer)
set_silent(model)

@variable(model, 0 <= x[1:T] <= 30)
set_start_value.(x, 9.0)

@objective(model, Max, sum(x))

cumx = [sum(x[1:t]) for t in 1:T]

# level_t ≥ l_min  ⇔  -ξ_t ≤ l_0 - l_min - cumx_t,  and  -ξ ~ N(-μ, Σ)
slack = [l_0 - l_min - cumx[t] for t in 1:T]
μ_negative = -μ

# One reliability window starting at period 1 and spanning all T periods (κ = T - 1)
add_JCC_SRD(model, slack, [1], T - 1, Σ,  μ_negative, p)

optimize!(model)

x_one = value.(x)
objective_value(model) # ≈ 28.43  (only the total is pinned down; the split over periods is not)


# ---------------------------------------------------------------
# Two-sided QMC: lower AND upper bound, l_min ≤ level_t ≤ l_max
# ---------------------------------------------------------------

model = Model(Ipopt.Optimizer)
set_silent(model)

@variable(model, 0 <= x[1:T] <= 30)
set_start_value.(x, [9.0, 10.0, 12.0])   # fill(9.0, T) does not converge here

@objective(model, Max, sum(x))

cumx = [sum(x[1:t]) for t in 1:T]

# l_min ≤ level_t ≤ l_max  ⇔  lower_t ≤ ξ_t ≤ upper_t
lower = [l_min - l_0 + cumx[t] for t in 1:T]
upper = [l_max - l_0 + cumx[t] for t in 1:T]

# Stack the bounds as [lower; upper] (length 2T). The random vector still has
# T components, so κ stays T - 1.
add_JCC_QMC(model, vcat(lower, upper), [1], T - 1, Σ, μ, p; two_sided = true)

optimize!(model)

x_two = value.(x)
objective_value(model) # ≈ 28.39, slightly below the single-sided value


# ---------------------------------------------------------------
# Monte Carlo check of the probability that the level stays in bounds
# ---------------------------------------------------------------

using Distributions, Random, Statistics

ξ = rand(MersenneTwister(1234), MvNormal(μ, Σ), 200_000)   # T × N scenarios

level(x) = l_0 .+ ξ .- cumsum(x)

mean(all(level(x_one) .>= l_min; dims = 1))                 # ≈ 0.9
mean(all((level(x_two) .>= l_min) .& (level(x_two) .<= l_max); dims = 1))  # ≈ 0.9

Individual-chance-constrained formulation

Instead of requiring the level to stay in bounds in all periods jointly, each period is constrained on its own:

\[\mathbb{P}(\ell_t \ge \ell_{\min}) \ge p, \qquad t = 1,\dots,T .\]

This ignores the correlation between periods. Because each ξ_t is a scalar Gaussian, ξ_t ~ N(μ_t, Σ_tt), every constraint has a closed form. With z_p = Φ⁻¹(p) and σ_t = √Σ_tt:

\[\mathbb{P}(-\xi_t \le \ell_0 - \ell_{\min} - \textstyle\sum_{s \le t} x_s) \ge p \iff \sum_{s \le t} x_s \le \ell_0 - \ell_{\min} + \mu_t - z_p\,\sigma_t .\]

These are linear in x, so no package call is needed:

using Distributions, LinearAlgebra

z = quantile(Normal(), p)
σ = sqrt.(diag(Σ))

model = Model(Ipopt.Optimizer)
set_silent(model)

@variable(model, 0 <= x[1:T] <= 30)
@objective(model, Max, sum(x))

cumx = [sum(x[1:t]) for t in 1:T]
@constraint(model, [t = 1:T], cumx[t] <= l_0 - l_min + μ[t] - z * σ[t])

optimize!(model)
x_ind = value.(x)
objective_value(model)

Two-sided version. The constraint P(lower_t ≤ ξ_t ≤ upper_t) ≥ p becomes

\[\Phi\!\left(\tfrac{\text{upper}_t - \mu_t}{\sigma_t}\right) - \Phi\!\left(\tfrac{\text{lower}_t - \mu_t}{\sigma_t}\right) \ge p ,\]

which is nonlinear but smooth. Using Φ(u) = ½(1 + erf(u/√2)):

using SpecialFunctions

Φ(u) = 0.5 * (1 + erf(u / sqrt(2)))

lower = [l_min - l_0 + cumx[t] for t in 1:T]
upper = [l_max - l_0 + cumx[t] for t in 1:T]

@constraint(model, [t = 1:T],
    Φ((upper[t] - μ[t]) / σ[t]) - Φ((lower[t] - μ[t]) / σ[t]) >= p)

Checking the joint probability. Reuse the Monte Carlo check from the joint example on x_ind:

mean(all(level(x_ind) .>= l_min; dims = 1))

Each period satisfies its own constraint with probability p, but the probability that all periods are satisfied together is generally lower than p. That gap is what the joint formulation closes.
