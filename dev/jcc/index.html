Computing probability functions

Using Quasi-Monte-Carlo

ChanceConstraints.compute_with_QMC — Function
    compute_with_QMC(j, κ, Σ, μ; two_sided=false, s=10_000, rng=MersenneTwister(1234))

Compute a quasi-Monte Carlo (QMC) approximation of a joint probability and its gradient.

Let $\xi$ be a random vector with mean $\mu$ and covariance matrix $\Sigma$. For the indices $i = j, \ldots, j+\kappa$, the one-sided probability is

\[f(x) = \mathbb{P}\bigl(x_i \geq \xi_i,\; i = j, \ldots, j+\kappa\bigr).\]

When two_sided=true, the probability is computed using the corresponding two-sided inequalities.

Returns (f, ∇f), where f is the estimated probability and ∇f is its gradient with respect to $x$. The gradient is computed using the Prékopa theorem, as described in Section X.

Arguments

  • j::Integer: Starting index of the components in $\Sigma$ and $\mu$.
  • κ::Integer: Number of additional components. The joint event includes indices $j, \ldots, j+\kappa$.
  • Σ::AbstractMatrix: Covariance matrix of $\xi$.
  • μ::AbstractVector: Mean vector of $\xi$.

Keyword Arguments

  • two_sided::Bool=false: Whether to use two-sided inequalities.
  • s::Integer=10_000: Number of QMC samples.
  • rng=MersenneTwister(1234): Random number generator for sampling. The fixed default seed makes estimates repeatable across solver iterations, which can help optimization converge. For standalone probability evaluation with a non-fixed random source, pass RandomDevice().

Using Spherical Radial Decomposition

Restriction for SRD. The spherical-radial decomposition method requires p > 1/2, and the mean μ must be a strictly feasible point (guaranteed through an implementation of the lower bound x ≥ μ + δ within the SRD functions).

For smaller probability levels, which are rarely of practical relevance, use the QMC method.

ChanceConstraints.compute_with_SRD — Function
    compute_with_SRD(w, κ, transformed_samples, μ)

Compute a spherical radial decomposition (SRD) approximation of a joint probability and its gradient.

For the indices $i = w, \ldots, w+\kappa$, the probability is

\[f(x) = \mathbb{P}\bigl(x_i \geq \xi_i,\; i = w, \ldots, w+\kappa\bigr),\]

where the random-variable samples used in the SRD calculation are provided by transformed_samples, and $\mu$ is the mean vector.

Returns (f, ∇f), where f is the estimated probability and ∇f is its gradient with respect to $x$. The gradient is computed using the Prékopa theorem, as described in Section X.

Arguments

  • w::Integer: Starting index of the components in the joint event.
  • κ::Integer: Number of additional components in the event; the event covers indices $w, \ldots, w+\kappa$.
  • transformed_samples::AbstractMatrix: Transformed samples used by the SRD calculation.
  • μ::AbstractVector: Mean vector used in the probability calculation.

Adding chance constraints to a JuMP model

Using Quasi-Monte-Carlo

ChanceConstraints.add_JCC_QMC — Function
    add_JCC_QMC(m, x, idx, κ, Σ, μ, p; two_sided=false, s=10_000, rng=MersenneTwister(1234))

Add a system of joint chance constraints to a JuMP model.

For each starting index $j \in \texttt{idx}$, the added constraint is

\[\mathbb{P}\bigl(x_i \geq \xi_i,\; i = j, \ldots, j+\kappa\bigr) \geq p,\]

where $\xi$ is a random vector with mean $\mu$ and covariance matrix $\Sigma$. When two_sided=true, the probability uses the corresponding two-sided inequalities.

The probability is approximated using quasi-Monte Carlo (QMC). The function registers it as a user-defined operator in the JuMP model and supplies the gradient computed by compute_with_QMC.

Arguments

  • m::JuMP.Model: JuMP model to which the constraints are added.
  • x::AbstractVector: Decision variables used in the constraints.
  • idx::AbstractArray: Starting indices of the reliability windows.
  • κ::Integer: Number of additional components in each window; each probability covers indices $j, \ldots, j+\kappa$.
  • Σ::AbstractMatrix: Covariance matrix of $\xi$.
  • μ::AbstractArray: Mean vector of $\xi$.
  • p::Float64: Minimum required probability level.

Keyword Arguments

  • two_sided::Bool=false: Whether to use two-sided inequalities.
  • s::Integer=10_000: Number of QMC samples.
  • rng=MersenneTwister(1234): Random number generator for QMC sampling. The fixed default seed makes estimates repeatable across solver iterations, which can help optimization converge. For standalone probability evaluation with a non-fixed random source, pass RandomDevice().

Using Spherical Radial Decomposition

ChanceConstraints.add_JCC_SRD — Function
    add_JCC_SRD(model, x, idx, κ, Σ, μ, p; s=100_000, seed=1234)

Add a system of joint chance constraints to a JuMP model using spherical radial decomposition (SRD).

For each starting index $j \in \texttt{idx}$, the added constraint is

\[\mathbb{P}\bigl(x_i \geq \xi_i,\; i = j, \ldots, j+\kappa\bigr) \geq p,\]

where $\xi$ is a random vector with mean $\mu$ and covariance matrix $\Sigma$.

The probability is computed using compute_with_SRD. The function registers it as a user-defined operator in the JuMP model and supplies its gradient, also computed using compute_with_SRD.

Arguments

  • model::JuMP.Model: JuMP model to which the constraints are added.
  • x::AbstractVector: Decision variables used in the constraints.
  • idx::AbstractVector: Starting indices of the reliability windows.
  • κ::Integer: Number of additional components in each window; each probability covers indices $j, \ldots, j+\kappa$.
  • Σ::AbstractMatrix: Covariance matrix of $\xi$.
  • μ::AbstractVector: Mean vector of $\xi$.
  • p::Real: Minimum required probability level.

Keyword Arguments

  • s::Integer=100_000: Number of samples used by the SRD computation.
  • seed::Integer=1234: Seed used for the random-number generation. The default makes the estimates repeatable across solver iterations, which can help optimization converge.
