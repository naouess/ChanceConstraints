Computing probability functions

Using Quasi-Monte-Carlo

ChanceConstraints.compute_with_QMC — Function
    compute_with_QMC(j, κ, Σ, μ; two_sided=false, s=10_000, rng=MersenneTwister(1234))

Compute a quasi-Monte Carlo (QMC) approximation of a joint Gaussian probability and its gradient with respect to the deterministic bounds.

Let $\zeta = A\xi \sim \mathcal{N}(\mu, \Sigma)$ and let $I = \{j, \ldots, j+\kappa\}$ be a window of $q = \kappa + 1$ consecutive components. The returned function f evaluates, for bounds $h \in \mathbb{R}^q$,

\[F(h) = \mathbb{P}\bigl(\zeta_i \leq h_i,\; i \in I\bigr).\]

When two_sided=true, for bounds $(z, h) \in \mathbb{R}^{2q}$,

\[F(z, h) = \mathbb{P}\bigl(z_i \leq \zeta_i \leq h_i,\; i \in I\bigr).\]

Returns (f, ∇f). The arguments of f are h... (one-sided) or z..., h... (two-sided), each of length $q$. ∇f is the gradient of $F$ with respect to these arguments. The $r$-th partial derivative with respect to $h_r$ is the density of $\zeta_r$ at $h_r$ times the probability of the remaining components conditional on $\zeta_r = h_r$. The derivative with respect to $z_r$ has the same form with a negative sign. Both the probability and the conditional probabilities are QMC estimates, so ∇f is an approximation.

In the two-sided case the bounds should satisfy $z_i < h_i$ for all $i$. If this is violated, f returns 0 and ∇f returns the zero vector, and a warning is issued.

Arguments

  • j::Integer: Starting index of the window in $\Sigma$ and $\mu$.
  • κ::Integer: Number of additional components; the window is $j, \ldots, j+\kappa$.
  • Σ::AbstractMatrix: Covariance matrix of $\zeta = A\xi$.
  • μ::AbstractVector: Mean vector of $\zeta = A\xi$.

Keyword Arguments

  • two_sided::Bool=false: Whether to use two-sided inequalities.
  • s::Integer=10_000: Number of QMC samples.
  • rng=MersenneTwister(1234): Random number generator for sampling. The fixed default seed makes estimates repeatable across solver iterations, which can help optimization converge. For standalone probability evaluation with a non-fixed random source, pass RandomDevice().

Using Spherical Radial Decomposition

Restriction for SRD. The spherical-radial decomposition method requires p > 1/2, and the mean μ must be a strictly feasible point (guaranteed through an implementation of the lower bound h ≥ μ + δ within the SRD functions).

For smaller probability levels, which are rarely of practical relevance, use the QMC method.

ChanceConstraints.compute_with_SRD — Function
    compute_with_SRD(w, κ, transformed_samples, μ)

Build a spherical radial decomposition (SRD) approximation of a joint Gaussia probability and its gradient with respect to the deterministic bounds.

For the indices $i = w, \ldots, w+\kappa$, the probability is

\[F(h) = \mathbb{P}\bigl(\zeta_i \leq h_i,\; i \in I\bigr),\]

where the samples used in the SRD calculation are provided by transformed_samples, and $\mu$ is the mean vector of $\zeta$.

Returns (f, ∇f). The arguments of f are h..., of length $q$. ∇f is the gradient of $F$ with respect to these arguments. For each sampled direction, the derivative is the chi density at the radial distance to the boundary, times the derivative of that distance with respect to the active bound. The bounds must satisfy $h_i > \mu_i$.

Arguments

  • w::Integer: Starting index of the window.
  • κ::Integer: Number of additional components in the window; the window covers indices $w, \ldots, w+\kappa$.
  • transformed_samples::AbstractMatrix: Transformed samples used by the SRD calculation.
  • μ::AbstractVector: Mean vector of $\zeta = A\xi$.

The probabilities and gradients are computed using the function ProbFunction:

ChanceConstraints.ProbFunction — Function
    ProbFunction(h, SampleOnSphere, mu)

Estimate the probability that each component of the Gaussian vector $\zeta = A\xi \sim \mathcal{N}(\mu, \Sigma)$ is smaller than or equal to the corresponding bound $h_i$:

\[\mathbb{P}(\zeta_i \leq h_i \text{ for all } i).\]

The estimate uses the spherical-radial decomposition. Each row of SampleOnSphere is a direction $L v$, where $v$ is a point on the unit sphere and $L$ is the Cholesky factor of $\Sigma$. For each direction, the radial distance to the boundary of the region $\{\zeta \leq h\}$ is computed, and the probability is the average of the chi CDF at these distances. This requires $h_i > \mu_i$ for all $i$.

Arguments

  • h: Vector of upper bounds, $h_i > \mu_i$.
  • SampleOnSphere: Transformed samples $L v$ used in the probability estimate.
  • mu: Mean vector of $\zeta$.

Adding chance constraints to a JuMP model

Using Quasi-Monte-Carlo

ChanceConstraints.add_JCC_QMC! — Function
    add_JCC_QMC!(m, h, idx, κ, Σ, μ, p; z=nothing, two_sided=false, s=10_000, rng=MersenneTwister(1234))

Add a system of joint chance constraints to a JuMP model.

Let $\zeta = A\xi \sim \mathcal{N}(\mu, \Sigma)$, and let $h$ (and, in the two-sided case, $z$) be vectors of affine JuMP expressions in the decision variables, e.g. h = B*x .+ c. For each starting index $j \in \texttt{idx}$, with window $I_j = \{j, \ldots, j+\kappa\}$, the added constraint is

\[\mathbb{P}\bigl(\zeta_i \leq h_i(x),\; i \in I_j\bigr) \geq p,\]

or, when two_sided=true,

\[\mathbb{P}\bigl(z_i(x) \leq \zeta_i \leq h_i(x),\; i \in I_j\bigr) \geq p.\]

where $\xi$ is a random vector with mean $\mu$ and covariance matrix $\Sigma$. When two_sided=true, the probability uses the corresponding two-sided inequalities.

The probability is approximated by quasi-Monte Carlo (QMC). For each window it is registered as a user-defined operator of the bounds, with the gradient supplied by compute_with_QMC. Because the bounds are affine, JuMP obtains the gradient with respect to the decision variables by the chain rule.

Arguments

  • m::JuMP.Model: JuMP model to which the constraints are added.
  • h::AbstractVector: Upper bounds $h(x)$, one affine expression per component of $\zeta$.
  • idx::AbstractArray: Starting indices of the windows.
  • κ::Integer: Number of additional components in each window.
  • Σ::AbstractMatrix: Covariance matrix of $\zeta = A\xi$.
  • μ::AbstractVector: Mean vector of $\zeta = A\xi$.
  • p::Float64: Minimum required probability level, $p \in (0,1)$.

Keyword Arguments

  • z=nothing: Lower bounds $z(x)$ (same length as h); required if two_sided=true.

The bounds must satisfy $z_i(x) < h_i(x)$ at every point where the constraint is evaluated; otherwise the probability is set to 0 and a warning is issued.

  • s::Integer=10_000: Number of QMC samples.
  • rng=MersenneTwister(1234): Random number generator for QMC sampling. The fixed default seed makes estimates repeatable across solver iterations, which can help optimization converge. For standalone probability evaluation with a non-fixed random source, pass RandomDevice().

Using Spherical Radial Decomposition

ChanceConstraints.add_JCC_SRD! — Function
    add_JCC_SRD!(model, h, idx, κ, Σ, μ, p; s=100_000, seed=1234)

Add a system of joint chance constraints to a JuMP model using spherical radial decomposition (SRD).

Let $\zeta = A\xi \sim \mathcal{N}(\mu, \Sigma)$, and let $h$ be a vector of affine JuMP expressions in the decision variables, e.g. h = B*x .+ c. For each starting index $j \in \texttt{idx}$, with window $I_j = \{j, \ldots, j+\kappa\}$, the added constraint is

\[\mathbb{P}\bigl(\zeta_i \leq h_i(x),\; i \in I_j\bigr) \geq p.\]

Only the one-sided formulation is available. The SRD requires $h_i(x) > \mu_i$, so the constraints $h_i(x) \geq \mu_i + 10^{-8}$ are added for all components covered by the windows.

The probability is computed using compute_with_SRD. For each window it is registered as a user-defined operator of the bounds, with the gradient supplied by compute_with_SRD. Because the bounds are affine, JuMP obtains the gradient with respect to the decision variables by the chain rule.

Arguments

  • model::JuMP.Model: JuMP model to which the constraints are added.
  • h::AbstractVector: Upper bounds $h(x)$, one affine expression per component of $\zeta$.
  • idx::AbstractVector: Starting indices of the windows.
  • κ::Integer: Number of additional components in each window.
  • Σ::AbstractMatrix: Covariance matrix of $\zeta = A\xi$.
  • μ::AbstractVector: Mean vector of $\zeta = A\xi$.
  • p::Real: Minimum required probability level, $p \in (0.5, 1)$.

Keyword Arguments

  • s::Integer=100_000: Number of samples used by the SRD computation.
  • seed::Integer=1234: Seed used for the random-number generation. The default makes the estimates repeatable across solver iterations, which can help optimization converge.
